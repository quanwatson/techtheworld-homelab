# 17-ots/

Ogun Tech Solutions (OTS) business build — runs on top of this same homelab hardware/network. Tracked here per the training program's vCIO Competency Track, which treats OTS as the applied/client-facing counterpart to the certification study.

- `proof-of-work/` — one record per project that would read well in an interview, using `proof-of-work-template.md` (PROJECT / DATE / BUSINESS PROBLEM / APPROACH / RESULT / CAREER VALUE format).
- `sops/` — standard operating procedures for recurring OTS work.
- `client-docs/` — client-facing documentation (proposals, runbooks handed to a client, etc. — redact anything sensitive before committing).
