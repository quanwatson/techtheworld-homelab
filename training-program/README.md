# training-program/

File-of-record mirror of the 36-month Solutions Architect + vCIO certification and career development plan. Claude (the Homelab project on claude.ai) keeps the authoritative copies of these documents — treat this folder as a working mirror, re-synced here whenever a doc gets updated in a session, not the other way around.

## Contents

- `Master-Training-Program.md` — the full reference doc: reasoning, hour estimates, certification currency, risk register, the 36-month calendar, the vCIO Competency Track, and the future-proofing pass.
- `Training-Time-Log.md` — per-session logged training hours, self-reported at session start and tallied against the plan's estimates.
- `Homelab-Stack-Inventory.md` — current hardware/software/network inventory backing the plan's lab-dependent objectives.

## Relationship to the rest of this repo

This folder tracks the *plan*. The numbered folders (`00-overview/` through `14-runbooks/`) track the *build* — what has actually been done on the homelab itself. They are related but not the same timeline: see the `01-logs/build-journal.md` entry dated 2026-09-14 for a note on where the two currently stand relative to each other.

- `15-certifications/` — study notes, practice-exam logs, and glossary additions that support the certifications named in this plan.
- `16-career/` — skill matrix history, monthly reviews, and the proof-of-work index this plan produces.
- `17-ots/` — Ogun Tech Solutions (OTS) business build, run on top of this same homelab.
- `18-solutions-architecture-adrs/` — architecture decision records for the Solutions Architect track specifically (distinct from `04-security/architecture.md`, which documents the homelab's own security architecture).
