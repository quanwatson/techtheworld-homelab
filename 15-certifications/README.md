# 15-certifications/

Working folder for the certifications named in `training-program/Master-Training-Program.md`. This is where day-to-day study material lives; the plan itself (hour estimates, sequencing, risk register) stays in `training-program/`.

- `study-notes/` — per-certification study notes, one subfolder or file per cert as they're started.
- `practice-exam-logs/` — dated practice-exam attempts and scores, using `practice-exam-log-template.md`.
- `glossary-additions/` — new terms encountered during study, staged here before being folded into the project's Glossary of Key Terms doc.
