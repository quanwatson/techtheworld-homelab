# 18-solutions-architecture-adrs/

Architecture Decision Records (ADRs) for the Solutions Architect track — decisions about how systems are designed, not how the homelab network/security baseline is configured. `04-security/architecture.md` documents the homelab's own security architecture and stays where it is; this folder is for the broader design decisions the training program calls for (e.g., the AI Gateway VLAN, the MCP + n8n control-plane choice, RAG memory tiering) plus any client-facing (OTS) architecture decisions.

One ADR per real decision, using `adr-template.md`. Number them sequentially (`0001-`, `0002-`, ...) in the filename.
